Setup: what this version can and can't do

This dashboard runs entirely in your browser. Content, media and revisions are saved in this browser's storage (IndexedDB). Publishing updates the site in this browser only.

To go live for all visitors you need a backend: a database for content, file storage for images, server-side login, and a host that serves sitemap.xml, robots.txt, 301 redirects and real 404s. Supabase plus Netlify/Vercel, or WordPress with Rank Math, both fit. Use Download backup to move your content across.

The sign-in here is a convenience lock, not real security: anyone with access to this browser's developer tools could bypass it.
